## 验证范围与限制

- `npm run check`：所有 JavaScript 语法检查。
- `npm test`：48 项规则、HTTP、桌面进程与双语测试。
- `npm ci --dry-run --ignore-scripts --offline`：锁文件一致性。
- 实际 macOS 浏览器检查登录、英文界面、root 参数入口与英文内置手册。
- Windows 路径逻辑在 path.win32 上验证；跨平台打包不代表已在 Windows / Linux / Intel Mac 实机验证。
- 单进程服务、同步密码哈希和同步 SQLite 存档仍有吞吐上限。大型公开服需要单独压测；不宣称支持任意地图规模或并发人数。
- 私信保存在服主的数据库中。普通 API 保证只对收发双方可见，但不提供对服主的端到端加密。
