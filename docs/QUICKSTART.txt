方域 · Squarelands / 1.2
=======================================

【服主 / HOST】
1. 解压 Server 包并运行 Squarelands Server（Linux: squarelands-server）。
   Extract the Server package and run Squarelands Server.
2. 保存控制台首次显示的 root 密码，将局域网连接地址分享给玩家。
   Save the initial root password and share the LAN address with players.
3. 同机游玩用 127.0.0.1:3210；停服后可备份存档或修改监听配置。
   For local play use 127.0.0.1:3210. Stop the world before backups/config changes.

【玩家 / PLAYER】
1. 解压 Client 包，运行 Squarelands Client（Linux: squarelands-client）。
   Extract the Client package and run Squarelands Client.
2. 填写服主提供的 IP 或域名，连接后注册或登录。
   Enter the host's IP or domain, connect, then register or sign in.
3. 首城免费，先保民生。升级增加领地容量，地块需手动解锁。
   Your first city is free. Secure essentials; claim adjacent tiles manually.
4. 语言按钮切换中文 / English；游戏右上角 ? 提供完整双语玩法手册。
   Use the language button; ? opens the full bilingual in-game handbook.
5. root 登录后在“管理 > 世界参数”调整各项数值，修改随存档保存。
   Root can adjust numeric settings in Admin > World parameters.

【平台 / PLATFORM】
Windows: 保留整个解压目录 / Keep the complete extracted folder.
macOS: 将 .app 拖入应用程序；arm64=Apple 芯片，x64=Intel。
       Drag .app to Applications; arm64=Apple Silicon, x64=Intel.
Linux: tar -xzf package.tar.gz，需图形桌面 / Desktop environment required.

应用内置运行时，无需另装 Node.js、npm 或数据库。
Runtimes are bundled; Node.js, npm and database installation are not required.
应用包未签名。公网连接需自行配置防火墙、域名或反代。
Packages are unsigned. Configure firewall/domain/proxy for internet access.
升级前安全停服并完整备份；不要同时运行两个服务端打开同一存档。
Stop and back up before upgrading. Never share a save between running servers.
