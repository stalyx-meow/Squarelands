方域 · Squarelands / 1.1
=======================================

【服主】
1. 解压 Server 包，运行 Squarelands Server（Linux: squarelands-server）。
2. 应用默认自动启动，首次 root 密码显示在世界控制台，请保存。
3. 将控制台显示的局域网地址发给玩家。同机游玩用 127.0.0.1:3210。
4. 停服、改端口、打开存档目录和备份都可在控制台操作。

【玩家】
1. 解压 Client 包，运行 Squarelands Client（Linux: squarelands-client）。
2. 输入服主给的 IP 或域名，点击“连接世界”。
3. 注册 / 登录账户后选择地块建城，按“?”查看玩法。
4. 关闭游戏窗口会返回连接页；菜单“游戏 > 切换服务器”可更换世界。

【平台】
Windows：将整个解压目录保留完整，再运行其中的 .exe。
macOS：将解压出的 .app 拖入“应用程序”。arm64 用于 Apple 芯片，x64 用于 Intel。
Linux：tar -xzf 包名.tar.gz，运行解压目录中的对应程序。需要图形桌面环境。

所有发布包内置运行时，不需要另装 Node.js、npm 或数据库。
这些是未做发行者签名的便携包。公网连接需要自行配置防火墙 / 域名 / 反向代理。
不要将 127.0.0.1 发给其他电脑；不要把存档保存在应用程序目录中。
完整说明请阅读源码中的 readme.md、DEVELOPMENT.md 和 GAMEPLAY.md。
